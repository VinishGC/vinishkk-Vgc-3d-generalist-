Who I am

I'm Vinish Kumar Kashyap, a 3D generalist and B.Tech IT student at Rajkiya Engineering College, Banda. I work across the full 3D pipeline in Blender — modeling characters and interiors, unwrapping and texturing, lighting scenes, and rendering them out in Cycles.

Alongside 3D, I build the web pages and tools that end up hosting that work, so I think about a piece from the moment it's a blockout in Blender to the moment someone sees it load on a screen.

I'm currently interning as a Java developer and a web developer, and using what I learn there to keep improving how my 3D work gets presented and shared.
